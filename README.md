# 元SATの人 / Instagram Reels 配信用メディア

This **public** repository holds only final MP4 media files to be fetched by Buffer when preparing Instagram drafts.

- Production source code, synthetic narration resources, persona documents and API credentials stay in the separate **private** production repository.
- GitHub Pages publishes files from `main:/docs`. There is no automatic Instagram publication.
- The homepage has `noindex` metadata, but **MP4 URLs are public**. Do not treat them as confidential.
- Only share reviewed, approved media. Keep media URLs stable until the corresponding posts are published.
- Repository title and folder access are not an access-control mechanism.
